# Sharon Kambe · Learning Experiences & Enrichment

Website for Sharon Kambe's one-to-one learning experiences for children aged 3–16 in Nairobi.

- `index.html`: homepage
- `rate-card.html`: the full rate card online (print or save as PDF from the page)
- `whatsapp.html`: the one-page card
- `assets/Sharon-Kambe-Rate-Card.pdf`: downloadable rate card
- `assets/Sharon-Kambe-One-Page-Card.png`: downloadable one-page card
- `assets/kambe-logo.png`, `assets/kambe-logo-transparent.png`: logo files

To publish: Settings → Pages → Deploy from a branch → `main` / root.
